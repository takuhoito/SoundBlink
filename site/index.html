Fix crackling USB audio on your Mac

A free menu bar app for when your USB speakers or DAC start to crackle. One click switches the output to the built-in speakers and straight back, the same trick that fixes it by hand, in about 0.2 seconds.

Sound familiar?

  • Your USB speakers, USB DAC or USB headset start to crackle, pop or sound distorted after a while.
  • They are connected through a monitor, a dock or a USB hub.
  • Switching the output to the built-in speakers and back makes the noise go away, until the next time.

Reports like this have become common since macOS Tahoe, especially on Apple silicon Macs, and there is no official fix yet. SoundBlink automates the workaround.

How it works

  1. Switch away

    The default output moves to the built-in speakers. They are muted first, so nothing leaks out.

  2. Wait for the stop

    As soon as your USB device has actually stopped, usually within a few hundredths of a second, SoundBlink switches back.

  3. Clean again

    Core Audio restarts your device, which clears the distortion.

≈ 0.2 s

The whole gap is typically around 0.2 seconds. If the built-in speakers are already the output, SoundBlink does nothing. On a Mac without built-in speakers, it switches through another output device instead.

Features

One click

Click the menu bar icon to reset. Right-click or Control-click for the menu.

Periodic reset

Every 10, 30 or 60 minutes, or turn it off. Skipped while audio is playing.

After sleep

Optionally resets a few seconds after your Mac wakes up.

Per-device control

All external devices are reset automatically by default. Uncheck the ones that don't need it.

Command line

Run SoundBlink --reset from Shortcuts, Raycast or Stream Deck.

Quiet and private

No network access, no data collection, no special permissions. English and Japanese.

Install

  1. Download SoundBlink.zip, unzip it and move SoundBlink.app to the Applications folder.
  2. SoundBlink is not notarized by Apple yet, so macOS blocks the first launch. Open it once, then go to System Settings → Privacy & Security and click Open Anyway. Or run this in Terminal: 
    xattr -dr com.apple.quarantine /Applications/SoundBlink.app
  3. Right-click the menu bar icon and turn on Launch at Login.

Requires macOS 13 Ventura or later. Universal app for Apple silicon and Intel Macs. Every release is built from the public source code by GitHub Actions.

FAQ

Will a reset interrupt my music?

Briefly, for about 0.2 seconds. Periodic resets are skipped while audio is playing (you can change this), so in practice they happen while your Mac is quiet.

The noise keeps coming back. Can I fix it for good?

SoundBlink is a workaround. The cause is in macOS or in the USB connection. Things worth trying:

Connect the audio device directly to the Mac instead of through a monitor or hub. Avoid putting two USB audio devices, such as a USB microphone and USB speakers, on the same USB 2.0 hub.

A reset doesn't clear the noise.

An app that is set to a specific output device, rather than the system default, may keep its own stream open. Set that app's speaker to the system default, for example in the audio settings of Zoom or Teams.

You can also make SoundBlink stay on the built-in speakers a little longer:

defaults write io.github.takuhoito.soundblink blinkHold -float 0.3

If that doesn't help, please open an issue with the output of SoundBlink --list.

Why does macOS say it can't check the app for malicious software?

Notarization requires a paid Apple Developer Program membership, which this free project doesn't have yet. The source code is public, and every release is built from it by GitHub Actions.

Does SoundBlink collect any data?

No. It doesn't connect to the internet at all.

How do I uninstall it?

Turn off Launch at Login, quit SoundBlink and move it to the Trash. To remove its settings too, run:

defaults delete io.github.takuhoito.soundblink
