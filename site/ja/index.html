SoundBlink
English GitHub

Mac の USB オーディオの音割れを、ワンクリックで直す

USB スピーカーや USB DAC の音がガビガビになったときのための、無料のメニューバーアプリです。出力先を一瞬だけ内蔵スピーカーに切り替えて戻す、手作業で直すときと同じ操作を、約 0.2 秒で行います。

こんな症状はありませんか？

  • USB スピーカーや USB DAC、USB ヘッドセットの音が、しばらくするとガビガビ・バリバリと割れたり、プチプチとノイズが乗ったりする
  • モニターやドック、USB ハブ経由でつないでいる
  • 出力先を一度内蔵スピーカーに切り替えて戻すと直る（でも、またそのうち起きる）

macOS Tahoe 以降、特に Apple シリコンの Mac でこうした報告が増えていますが、公式な修正はまだありません。SoundBlink は、この回避策を自動で行います。

仕組み

  1. 切り替える

    出力先を内蔵スピーカーに切り替えます。先にミュートするので、本体から音は漏れません。

  2. 止まるのを待つ

    USB 機器が実際に止まったら（たいてい数百分の 1 秒で止まります）、すぐに元に戻します。

  3. 元どおり

    CoreAudio が機器を起動し直すので、音割れが消えます。

約 0.2 秒

音が途切れるのは、全体でたいてい 0.2 秒ほどです。すでに内蔵スピーカーから出力しているときは何もしません。内蔵スピーカーのない Mac では、ほかの出力デバイスを経由して切り替えます。

機能

ワンクリック

メニューバーのアイコンをクリックするとリセットします。右クリック（または Control+クリック）でメニューを開きます。

定期リセット

10・30・60 分ごとに実行します。オフにもできます。再生中はスキップします。

スリープ復帰時

Mac がスリープから復帰した数秒後にリセットします（オプション）。

デバイスごとに選べる

最初は外部の出力デバイスすべてが自動リセットの対象です。不要なデバイスはチェックを外せます。

コマンドライン

ショートカット.app や Raycast、Stream Deck から SoundBlink --reset で呼び出せます。

静かで安全

ネットワークに接続せず、データも集めません。特別な権限も不要です。表示は日本語と英語に対応しています。

インストール

  1. SoundBlink.zip をダウンロードして展開し、SoundBlink.app を「アプリケーション」フォルダに移動します。
  2. まだ Apple の公証（notarization）を受けていないので、初回起動は macOS にブロックされます。一度開こうとしたあと、システム設定 → プライバシーとセキュリティ で「このまま開く」を押してください。ターミナルで次のコマンドを実行しても開けるようになります。 
    xattr -dr com.apple.quarantine /Applications/SoundBlink.app
  3. メニューバーのアイコンを右クリックし、「ログイン時に起動」をオンにします。

macOS 13 Ventura 以降で動きます。Apple シリコンと Intel の両方に対応したユニバーサルアプリです。リリースはすべて、公開しているソースコードから GitHub Actions でビルドしています。

よくある質問

リセットすると音楽が途切れますか？

0.2 秒ほど途切れます。定期リセットは再生中にはスキップするので（設定で変えられます）、実際には音を出していないときに行われます。

何度も再発します。根本的に直せませんか？

SoundBlink は回避策で、原因は macOS か USB の接続経路にあります。次の方法を試してみてください。

オーディオ機器を、モニターやハブ経由ではなく Mac 本体に直接つなぐ。USB マイクと USB スピーカーのように、USB オーディオ機器を 2 台同じ USB 2.0 ハブにつながない。

リセットしても音割れが直りません

アプリ側で出力デバイスを「システムのデフォルト」ではなく特定のデバイスに固定していると、そのアプリは自分の音声ストリームを開いたままにすることがあります。Zoom や Teams などの音声設定で、スピーカーを「システムのデフォルト」にしてください。

内蔵スピーカーにとどまる時間を長くすることもできます。

defaults write io.github.takuhoito.soundblink blinkHold -float 0.3

それでも直らないときは、SoundBlink --list の出力を添えて Issue を立ててください。

「悪質なソフトウェアかどうかを確認できません」と表示されるのはなぜですか？

公証を受けるには有料の Apple Developer Program への登録が必要で、この無料のプロジェクトはまだ登録していないためです。ソースコードは公開していて、リリースはすべてそこから GitHub Actions でビルドしています。

データを集めていますか？

いいえ。インターネットには一切接続しません。

アンインストールするには？

「ログイン時に起動」をオフにしてから SoundBlink を終了し、ゴミ箱に入れてください。設定も消すときは、次のコマンドを実行します。

defaults delete io.github.takuhoito.soundblink
